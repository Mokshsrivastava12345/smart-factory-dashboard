Smart Factory Dashboard 🏭

A smart manufacturing dashboard for monitoring **production, machine health, energy consumption, and operational performance** in real time.

## What it does

* 📊 Tracks production output, efficiency, downtime, and energy consumption
* ⚙️ Monitors machine health and utilization
* 🌐 Includes a 3D digital twin of the factory floor
* 📈 Shows production and energy trends
* 🤖 Provides AI-based insights and risk detection
* 📁 Allows CSV data upload and analysis

## Tech Stack

* Python
* Pandas & NumPy
* Scikit-learn
* Three.js
* Chart.js
* Streamlit

## Key Concepts

**Smart Manufacturing • Data Analytics • Digital Twin • Predictive Maintenance • AI • Real-Time Monitoring**

## Project Goal

The goal is to bring factory data into one place and turn it into **simple, useful insights that can help improve operational decisions.**
